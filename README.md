# Stylized Shader

A collection of procedural stylized shading assets for Blender, designed to help artists create distinctive illustrated, comic, and painterly visual styles.

## Features

Stylized Shader includes **13 shader assets** organised into five categories:

### 01. Cel Shading
Creates stylized shading with distinct tonal regions, inspired by traditional animation and cartoon artwork.

### 02. Halftone
Adds comic-book-inspired halftone dot patterns to materials.

### 03. Hatching
Creates hand-drawn, line-based shading inspired by traditional illustration techniques.

### 04. Watercolor
Produces painterly, watercolor-inspired shading effects.

### 05. Outlines
Adds stylized outlines to objects for an illustrated or comic-book appearance.

## Asset Variations

Several shading categories include three variations:

- **Standard** – The default effect.
- **Custom Tone** – Allows users to customise the colours used by the shader.
- **Light Reactive** – Uses lighting information to influence the shader's appearance.

## Requirements

- Blender 5.3 or newer.

## Installation

Stylized Shader is intended to be distributed as a Blender Asset Library Extension.

Once the extension is available, install it through Blender and access the assets through the Asset Browser.
